# PerfoTec buyer-journey redesign demo

A Vite/React concept for pitching a clearer B2B buyer journey to PerfoTec.

## Run locally

```bash
npm install
npm run dev
```

## Build for Vercel

```bash
npm run build
```

Vercel settings:

- Framework preset: Vite
- Build command: `npm run build`
- Output directory: `dist`
- Install command: `npm install`
- Root directory: `/`

## Demo interactions

- Responsive navigation and smooth-scroll sections
- Hero audience slider
- Buyer-path selector for four customer types
- Solution/product tabs
- Technical spec panel
- Case-study links
- FAQ accordion
- Inquiry modal with a path selector and success state
- Official contact, technology PDF, case-study, and product-page links

## Before production

1. The demo now uses local copies of publicly visible PerfoTec logo/product/case-study assets. Confirm permission and replace or keep them according to PerfoTec’s brand and asset-use policy.
2. Connect the inquiry form to the real PerfoTec inbox or CRM.
3. Confirm technical figures and product claims with the PerfoTec team.
4. Add approved case-study outcomes, customer names, and ROI evidence where available.
5. Confirm the design direction, logo usage, typography, and brand colors with PerfoTec.

See `RESEARCH_NOTES.md` for evidence and uncertainty boundaries.
